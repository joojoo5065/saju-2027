# 2027 신년운세

생년월일시를 넣으면 2027 정미년(丁未)의 총운·12달 흐름·일·직장운·재물운·연애·인간관계운을 쉬운 말로 풀어 주는 정적 웹페이지.

- 계산은 브라우저 안에서만 이뤄지고, 입력값을 어디에도 보내거나 저장하지 않는다.
- `engine.js` — 만세력·십성·용신·대운·세운 계산 엔진 (saju-career와 같은 사본)
- `index.html` — 입력 화면 + 풀이(4챕터 + 풀이 근거) 규칙표와 화면
- URL로 바로 열기: `?y=1999&m=6&d=18&h=9&mi=5&g=F&s=work&l=single&n=이름`
  - `h` 생략 = 시각 모름 · `s=work|prep` · `l=single|couple`
  - `p=seoul|busan|…` = 태어난 곳 시간 보정, `p=etc&lon=127.4` = 경도 직접 입력 (`c=1` = 예전 링크, 서울로 처리)
- 시간 보정(분) = (출생지 경도 − 표준시 기준 경도) × 4. 기준 경도는 1954.3.21~1961.8.9 = 127.5°, 그 밖 = 135°. 서머타임은 빼지 않음.
